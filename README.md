# StudentHub

StudentHub is a web-based student portal designed to provide students with a centralized platform for accessing academic and campus-related information.

## Features

* Student Login & Registration
* Student Dashboard
* Courses
* Assignments
* Study Resources
* Attendance
* Timetable
* Notices & Events
* Student Profile
* Help & Support

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* VS Code
* Figma / Draw.io

## Project Structure

```text
StudentHub/
├── index.html
├── pages/
├── css/
├── js/
├── images/
└── docs/
```

## Project Goal

To develop a simple, responsive, and user-friendly student portal that organizes commonly required academic and campus services in one place.
